# Informal user story

**Persona:** Alex is a consultant juggling several client engagements. They need a single place to capture follow-ups with a clear status and due date so nothing slips before the weekly status meeting.

**Story:** As Alex, I want to sign in to a small task board, see my existing items at a glance, and add or adjust tasks (title, description, status, due date) so I can prioritize work for the week and mark items done as I finish them.

**Acceptance (demo script):**

- I can register a new account or sign in with known demo credentials.
- After sign-in, I see only my tasks.
- I can create a task, edit it, and delete it; changes persist after refresh.
- The UI works on a laptop-width browser window without horizontal scrolling.

This matches the implemented React SPA plus Identity and Tasks APIs described in the root [README](../README.md).
